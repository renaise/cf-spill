The rule

No source, no record.

It is not a moderation policy. It is enforced in the archive's API, which refuses a record and tells you in plain words which document is missing.

A claim and a document Every record pairs the statement with something anyone can open. A filing, a cache, an archive link.
Nothing is ranked No likes, no scores, no trending. A crowd cannot vote a document into existence, and ranking claims by popularity would make this a publisher rather than a record.
Names are optional File without one. The document carries the weight, so the person filing does not have to.
Status

Four states, and none of them is a verdict on a person.

Status describes the claim against the documents. Fraud, lie and false are deliberately unavailable, because intent cannot be sourced and so cannot be published.

Supported

A document corroborates the claim.

Contradicted

A named document states something incompatible with it.

Unsupported

Nothing was found either way. The honest default, and not an accusation. Most records should say this.

Uncheckable

No public document could settle it.

A filled square means a document is on file. A hollow ring means none was found. Both are drawn the same size, because “nothing found” is a real answer and dimming it would say it mattered less.
